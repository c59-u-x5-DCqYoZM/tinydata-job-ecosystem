The first vertical ecosystem: jobs, then travel

A synthetic UK job market you can run experiments on.

About 2,000 open jobs and the people who could fill them, across Professional & Business Services, Technology & Digital and Finance & Insurance. The same population runs under different market designs, agents, rules and AI scenarios; every run reports the same 25 measures, so the differences are the findings.

“This needs to have real foundational layers, it needs to have real database layers, it needs to have real kind of operating uh, approaches that we can that we can use to ask economic questions”Soren, 5 October 2026

Five decisions that carry the weight

  1. One writer, typed actions, chained receipts in the careers vault format, so the ecosystem can be audited like the real vault.
  2. Hidden truth walled off from the vault, in code and in database grants, so signal value, shoehorning and fit over time can be measured honestly.
  3. Three agent tiers behind one interface, with every model call taped so any run replays without calling a model.
  4. One sampling fraction for people and jobs, so the market's tightness is real; the agreed 5,000 become the profiled tier. Needs your approval.
  5. A financial model that must reproduce Simon's plan to the pound, then re-runs it on the funnel each experiment actually produced, net of operator cost.
